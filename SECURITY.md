# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| 0.0.x   | :x:                |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email the maintainer at the address listed in [package.json](package.json) (`author` field) or use GitHub's [private vulnerability reporting](https://github.com/watzak/editable.ts/security/advisories/new) if enabled.

Include:

- Description of the issue
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

We aim to acknowledge reports within 7 days.

## Scope

This policy covers the `editable.ts` library published to npm (`lib/`, `dist/`). The demo site at GitHub Pages is out of scope for library vulnerabilities unless they expose users of the npm package.
