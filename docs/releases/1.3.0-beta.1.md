# Release notes — `1.3.0-beta.1` (draft)

**Status:** Prepared locally — **not published** (no npm tag, no GitHub release).

## Summary

First public beta of the optional **`editable.ts/yjs`** subpath: collaborative text editing with Yjs, plus experimental document binding, presence, and annotations. Core-only consumers are unaffected.

## Install

```bash
npm install editable.ts@1.3.0-beta.1
npm install yjs y-protocols   # optional peers, required for ./yjs
```

## Experimental APIs

| Export                                                            | Scope                               |
| ----------------------------------------------------------------- | ----------------------------------- |
| `EditableYjsBinding`                                              | Block-level CRDT sync               |
| `EditableYjsDocumentBinding`                                      | Multi-directive documents           |
| `EditableYjsPresence`                                             | Awareness overlays                  |
| `EditableYjsAnnotations`                                          | Persistent annotation map           |
| `createProviderStatusSource`, `activateBindingsAfterProviderSync` | Provider glue (no bundled provider) |

Mark imports with your own `@experimental` policy until `1.3.0` stable.

## Breaking change policy (beta)

Patch/minor releases may change `./yjs` APIs without a major bump while labeled experimental. Core `./` and `./features` follow normal semver.

## Known limitations

- No bundled provider — use `y-websocket` or custom transport (see demos)
- Real OS IME requires manual QA ([IME test plan](../YJS_IME_TEST_PLAN.md))
- Document binding + annotations: `@experimental`, adapter-owned schema
- Structural adapters are synchronous only
- GitHub Pages may require built `lib/` for Yjs HTML demos

## Migration from manual `Y.applyUpdate` demos

1. Add `deferInitialSync: true`
2. Map provider events to `YjsProviderStatus`
3. Call `binding.activate()` after `synced`
4. Keep destroy order: overlays → bindings → provider → editable
